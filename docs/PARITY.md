# 与原版 mdcx-diy 对齐计划（Parity Matrix & Roadmap）

> 目标：mcdx-docker 网页版与原版桌面应用**功能 100% 一致、操作习惯一致**。
> 基线：原版主窗口（影片刮削 / 工具 / 设置页签）、全部工具窗口、全部配置项、多模式刮削、右键菜单。
> 本文档为施工图：现状对照、差异点、分阶段路线图、验收口径。随实现持续更新。

## 0. 架构不变式（网页版对齐的工程前提）

- 后端复用原版核心（爬虫/刮削/nfo/命名/演员库/工具），无头化运行；网页只是"复刻原版的皮"。
- 全局单例（manager/Flags/LogBuffer）→ 服务内串行批次；进度/列表/日志走原版信号直连回调或 LogBuffer。
- 配置读写四步法（Config.update → model_validate → _replace_config → save），脱敏输出。
- 模式映射与原版 1:1：`main_mode` 1 正常 / 2 整理 / 3 更新 / 4 读取；单文件强制重刮 = `FileMode.Again`。
